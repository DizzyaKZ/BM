# BEERMOOD Master ERP v3 (Angular 18 + PHP/MySQL)
**Холдинг MOOD GROUP (BEERMOOD.PUB / MEAT & BREAD MOOD / CHEESY MOOD / SPICY MOOD LAB)**  
*Локация: Казахстан, г. Алматы, ул. Жарокова 137/1 (ЖК «Арай», блок Г3)*  
*Правообладатель: Спицын Павел Николаевич (Товарный знак BEERMOOD №68702)*

---

### Архитектура системы
1. **Frontend:** Angular 18 (Standalone Components, Signals Reactive Core, RxJS 7, ViewEncapsulation).
2. **Backend:** PHP 8.x REST API + MySQL 8.x Schema + TCP Socket Gateway к принтеру TSC TE310.
3. **Hardware Gateway:** 
   - Термотрансферный принтер: **TSC TE310** (IP: `192.168.1.17`, порт `9100`, 300 DPI).
   - Расходный материал: Лента **ТермоТОП 58×60 мм** (и 58×40 мм), зазор `GAP 2 mm`.
   - Анализатор молока: **«Эксперт Профи»** (ультразвуковой, пересчет по СТ РК / ГОСТ).

---

### Быстрый старт в Visual Studio Code (macOS / Windows)

```bash
# 1. Распаковка проекта (если запускаете единый скрипт-архив):
node create-beermood-master-erp-v3.js

# 2. Переход в папку проекта:
cd beermood-master-erp-v3

# 3. Установка зависимостей Angular 18:
npm install

# 4. Запуск сервера разработки:
npm start
# Приложение откроется в браузере: http://localhost:4200/
```

### Реализованные модули
- ⚡ **GIANT-планирование:** Мониторинг циклов сыроизготовителя Casaro (100л), коптильни «Ижица Varmen Mini» (25 кг), климатической камеры сушки билтонга (+14°C, 68%), печей Unox и кухни паба.
- 🧪 **Лаборатория приемки («Эксперт Профи»):** Входной контроль молока (жир, белок, СОМО, плотность, точка замерзания, фальсификация водой, pH, °T) с расчетом сыропригодности и печатью Акта приемки.
- 🛍️ **Заказы ЖК «Арай»:** Управление доставкой жильцам блоков Г1–Г4, скидка 10% MOOD CLUB, печать стикеров пакетов.
- 🍖 **Технологические карты Коха:** 12+ рецептур с пересчетом R1, R2, S1, S4b, S8 на рынок Алматы и Halal (Жая, Казы, Жал), экономика Takeaway vs Pub.
- 🧀 **Сыроварня & Пекарня:** Рецептуры Sacco MS062/MS064 и 100% Zero-Waste замес Тартинов на подсырной сыворотке.
- 🏷️ **Центр TSPL печати:** Генерация чистого кода CP1251, расчет штрихкодов EAN-13 и отправка на `192.168.1.17:9100`.
